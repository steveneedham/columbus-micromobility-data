Columbus Micromobility — Observer View

Demo / personal project

An independent, public-data-only look at Columbus shared-scooter operations — 311 requests, published vehicle positions, and policy boundaries. Built from public sources only; not affiliated with or using data from any employer.

Partial sample snapshot. The data embedded below was extracted from a size-capped fetch of github.com/steveneedham/311-Intel's public data feeds and is not the full dataset — see per-layer counts in the stat cards and the _extraction_note embedded in each JSON block below. This is a review signal for demo purposes, not a confirmed or complete picture of citywide activity. To see the full dataset, swap in the complete committed JSON files (columbus-311-current.json, gbfs-vehicle-positions.json, mobility-policy-boundaries.json) from that repo. This dashboard itself is destined for github.com/steveneedham/columbus-micromobility-data. Not an official Spin, Veo, or City of Columbus tool — not a confirmed-violation record system.
