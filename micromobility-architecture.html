Columbus Micromobility Data

GitHub Actions-driven data pipeline: collect → process → publish

Data Sources — Public APIs from operators and city (no auth required)
GitHub Actions Workflows — Automated fetch/process/publish on a schedule
Data Storage & Outputs — Committed to repo, published via GitHub Pages
Schedule Legend — Workflows run on fixed schedules or when triggered by upstream tasks
Key Characteristics:
  • Fully automated: No manual data pulls. GitHub Actions workflows run on schedules or trigger each other.
  • Public data only: No credentials or private APIs. All sources are read-only, no authentication.
  • Version controlled: All snapshots and data files committed to GitHub for audit trail and history.
  • Low overhead: Runs on GitHub's free tier. No servers, databases, or infrastructure to maintain.
  • Two main outputs: (1) Live interactive dashboard for exploration, (2) Scooter Challenge app for cost comparison.
